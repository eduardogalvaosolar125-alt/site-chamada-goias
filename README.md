# Site de chamada - Goiás Esporte Clube

## Como usar
1. Abra `index.html` no navegador.
2. Use os dados de acesso que já aparecem preenchidos.

## Recursos
- Login demonstrativo
- Três turmas de exemplo
- Presença, atraso, ausência e justificativa
- Busca e filtro de atletas
- Cadastro e exclusão de atletas
- Salvamento automático no navegador
- Layout responsivo para celular e computador

## Importante
Este é um protótipo sem servidor. Para operação oficial, é necessário acrescentar autenticação real, banco de dados, perfis de acesso, cópias de segurança e requisitos de LGPD. A marca visual oficial não foi reproduzida.
