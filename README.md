# Site de chamada - Goiás Esporte Clube

## Como usar
1. Abra `index.html` no navegador.
2. Use os dados de acesso que já aparecem preenchidos.

## Recursos
- Login demonstrativo
- Turmas de voleibol conforme a grade enviada
- Presença, atraso, ausência e justificativa
- Busca por turma, professor e atleta
- Cadastro e exclusão de atletas
- Salvamento automático no navegador
- Layout responsivo para celular e computador

## Importante
Este é um protótipo sem servidor. Antes do uso oficial, é necessário cadastrar os atletas de cada turma, definir as quadras e categorias marcadas como "A confirmar", acrescentar autenticação real, banco de dados, perfis de acesso, cópias de segurança e requisitos de LGPD. A marca visual oficial não foi reproduzida.
